constexpr Config pca9685::DirectLedPreset () noexcept
 LEDs wired from the supply through a resistor to the outputs (figure 15): open drain, inverted, so that a channel that is off leaves the output high impedance and the LED dark. Detailed Description

Public types of the PCA9685 driver: errors, Result<T>, channel values, configuration, presets and the frequency and pulse-width arithmetic.

Copyright
Copyright (c) 2026 The driver-pca9685 authors. SPDX-License-Identifier: MIT

Everything here is plain data and constexpr arithmetic with no platform dependency, so handlers, tests and tools can include it without the driver template. The configuration defaults are the chip's reset values (section 7.3), so Config{} describes a chip that was just reset.

Section, table and figure numbers refer to the NXP PCA9685 product data sheet, Rev. 4 (16 April 2015).
