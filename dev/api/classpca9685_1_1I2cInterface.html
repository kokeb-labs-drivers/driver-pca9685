Detailed Description

template<typename Derived>
class pca9685::I2cInterface< Derived >

CRTP base of the platform I2C port.

Derive class MyPort : public pca9685::I2cInterface<MyPort> and implement the hooks in this file's description. The base declares no hook itself (a forwarding hook would turn a missing override into infinite recursion) and no data; the driver checks your class with the I2cPort concept, so a missing or misdeclared hook is a compile error that names it.
