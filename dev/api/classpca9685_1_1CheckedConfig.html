Detailed Description

A configuration proven valid at build time.

constexpr CheckedConfig kBoard{Config{.pwm_frequency_hz = 50}}; fails to compile, naming ConfigIsInvalid, when Validate() rejects the configuration. Pass kBoard.Get() to the driver; the driver still validates at start-up, for configurations built at run time.
