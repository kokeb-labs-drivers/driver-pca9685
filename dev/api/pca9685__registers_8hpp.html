Detailed Description

PCA9685 register map: addresses, bit fields and reset values (datasheet section 7.3).

Registers are 8 bits wide. The control register (the first byte after the address) points at one; with MODE1.AI set the pointer moves to the next register after every byte, from LED15_OFF_H (0x45) back to MODE1 and from PRE_SCALE (0xFE) back to MODE1 (table 4, remark). With AI clear every byte of a transfer goes to, or comes from, the same register. Addresses 0x46 to 0xF9 are reserved and not acknowledged; 0xFF (TestMode) is reserved and never touched by the driver.

Section, table and figure numbers refer to the NXP PCA9685 product data sheet, Rev. 4 (16 April 2015).
