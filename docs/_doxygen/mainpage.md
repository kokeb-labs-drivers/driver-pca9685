# PCA9685 Driver API reference {#mainpage}

The classes, types and registers of the PCA9685 driver, generated from the headers in `inc/`.

Start with pca9685::PCA9685, the driver, and pca9685::I2cInterface, the base of the port you write. Errors are
pca9685::Error inside pca9685::Result; the configuration is pca9685::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">PCA9685 Driver
documentation</a>.
