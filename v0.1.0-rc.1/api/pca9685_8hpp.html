Detailed Description

PCA9685 driver: the one header to include.

Copyright
Copyright (c) 2026 The driver-pca9685 authors. SPDX-License-Identifier: MIT

pca9685::PCA9685<Port> drives one NXP PCA9685 16-channel, 12-bit PWM controller through a platform port you write (see pca9685_i2c_interface.hpp). The driver has no platform code, allocates nothing, throws nothing, takes no lock and is not thread-safe: give each object one owner, or guard it with one mutex.

Section, table and figure numbers refer to the NXP PCA9685 product data sheet, Rev. 4 (16 April 2015).
