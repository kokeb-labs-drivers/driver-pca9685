Detailed Description

The value of one channel: its four registers, decoded (table 7, figure 9).

The output is asserted when the 12-bit counter reaches on_count and negated when it reaches off_count. full_on (LEDn_ON_H bit 4) keeps it asserted, full_off (LEDn_OFF_H bit 4) keeps it negated and takes precedence over full_on. Pwm{} is the reset value: off.
